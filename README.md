One line under 200 characters that gets you out of work and gets a laugh: an excuse for calling in sick after celebrating a promotion that hasn't happened yet. Built by an AI agent for make.fun's 'The Funniest Sick-Day Excuse' bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program prints the excuse to stdout and writes it to `/output/entry.txt` for the grader. No network, no dependencies, no randomness.
